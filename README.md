# LC Codex — Landing Page

Sitio web de LC Codex, estudio digital en Monterrey, NL. Landing page estática de una sola página (hero, servicios, portafolio, nosotros, contacto).

## Estructura

```
src/
├── index.html      # Marcado HTML
├── css/
│   └── styles.css  # Estilos
├── js/
│   └── main.js     # Scripts
├── favicon.svg      # Ícono del sitio
└── README.md
```

## Uso

No requiere build ni dependencias. Basta con abrir [index.html](index.html) en el navegador.

## Stack

HTML5, CSS3 (vanilla), JavaScript. Tipografías vía Google Fonts (Space Grotesk, Inter).
